Connect Alpaca
Paste Alpaca paper keys once — they’re encrypted and saved to your Runnr account. After that, every device you sign in on links automatically.
Connect IBKR Flex
Read-only. In IBKR Account Management → Flex Web Service: create a Trade Confirmation or Activity Flex Query (XML), enable the Web Service, then paste the token + Query ID. Extend token validity beyond 6 hours if you sync often. Do not IP-restrict the token to your home network (Runnr syncs from the API server).
Connect Trading 212
Read-only. In Trading 212 go to Settings → API (Beta) and generate a key. Enable account, history, and portfolio. Leave orders off. Invest / Stocks ISA only — SIPP is not supported. Keys are encrypted on your Runnr account. We never place trades.
