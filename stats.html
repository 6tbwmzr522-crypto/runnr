How this is counted

On each load of index.html or login.html, the page sends a tiny beacon to our API. The server hashes the visitor’s IP address together with the UTC date and user-agent, using a secret that never leaves the server, then discards the IP. We store only that hash (to know if the visitor is new today) and the counters you see here. Hashes older than two days are deleted.

We do not store IP addresses. We do not use advertising cookies. We do not send this data to Google or any other analytics vendor. Public totals live only on this page. Details are in the Privacy Policy.
